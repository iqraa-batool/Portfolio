# Iqra Batool — Portfolio

Personal portfolio of Iqra Batool, WordPress Developer & AI Solutions Builder. Showcasing web development, AI-powered solutions, workflow automation, services, articles and contact information.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Services (`services.html`)
- Blog (`blog.html`)
- Contact (`contact.html`)

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` from the repository root.

Static HTML, CSS and JavaScript. No build step required.
